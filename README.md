# Radio

Live internet radio from around the world: 30,000+ stations from the
[Radio Browser](https://www.radio-browser.info) directory plus ad-free SomaFM channels.
Filter by genre, country, language and bitrate; favorites, history and blocked stations
stay on your device.

**Live:** [radio.freeappstore.online](https://radio.freeappstore.online)

Split out of [Music](https://github.com/freeappstore-online/music) (music#5).

## Development

```bash
pnpm install
pnpm dev
```

## Deploy

Push to main — auto-deploys via GitHub Actions.
